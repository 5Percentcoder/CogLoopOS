## Today’s flow

1. 在 Obsidian 里快速捕捉问题或阅读已有 loop。
2. 在 Codex 里用 `$run-learning-loop` 把值得验证的问题推进成闭环。
3. 回到 Obsidian 审查 Observation、Interpretation、Decision。
4. 用 `$review-learning-os` 做周期性健康检查。

## Use with Codex

开始一个真实学习主题：

```text
使用 $run-learning-loop，把“一个真实技术问题”跑成学习闭环。
```

审查系统健康状态：

```text
使用 $review-learning-os 审查本周学习系统。
```

## Operating principles

- 先冻结假设和验收条件，再运行实验。
- 原始证据与工程判断分开保存。
- 失败的假设也是有效学习成果。
- 不为了图谱漂亮而提前制造概念页面。
- completed loops 的语义修改需要人工审查。
